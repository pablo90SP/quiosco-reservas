# Quiosco Reservas
Aplicación web de venta y reserva para un quiosco de barrio. Proyecto Intermodular de 2º DAW Semipresencial – Pablo Pomares Soler.

## Problema que resuelve
Las reservas del quiosco se hacen por teléfono o en persona y se apuntan en una libreta: se reservan más unidades de las que hay, hay productos apartados que nunca se recogen y todo depende del titular.

## Descripción
El cliente consulta el catálogo con las unidades disponibles y reserva productos para recogerlos en el mostrador en una franja horaria. El empleado gestiona las entregas del día y el administrador gestiona productos, existencias, horarios, empleados y la información de paquetería.

## Funcionalidades previstas
- Registro e inicio de sesión con tres roles: cliente, empleado y administrador.
- Catálogo por categorías con precio y unidades disponibles.
- Crear, modificar y cancelar reservas sin superar las existencias.
- Liberación automática de las reservas no recogidas.
- Panel del empleado con las reservas del día.
- Gestión de productos, horario, empleados y paquetería.

## Tecnologías
React + Vite · Node.js + Express · MySQL 8 · Apache en Ubuntu Server
